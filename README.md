# Chemical Exposure Identification - PubMed Abstracts

A CSV consolidation of the *"Corpus and Software"* chemical-exposure dataset
(see [3. Attribution](#3-attribution)). One row per scientific article.

> ⚠️ NOTE: **Sentence-to-label mapping is discarded**. The original
> corpus annotates labels at the *sentence* level, but this CSV drops that
> mapping: each row is one full abstract, and the label columns are
> multi-label outputs for the whole abstract: a 1 means the label
> occurs somewhere in the abstract, not which sentence carried it.

Label columns are **ancestor-inclusive**: If an abstract is tagged `x/y/z`,
then `x`, `x/y`, and `x/y/z` are all set to `1`.

- GitHub (for additional details): https://github.com/AvirukBasak/chemical-exposure-pubmed-abstracts
- License: Attribution 4.0 International (CC BY 4.0)

## 1. What this is

- 3,661 PubMed abstracts, manually annotated for chemical exposure.
- Each abstract was tagged sentence-by-sentence with a hierarchical label from
  a 3-branch taxonomy: `biomonitoring`, `exposure routes`,
  `site comparisons`: 69 nodes, max depth 5.
- Here the sentence-level labels are rolled up into one row per article and
  stored as binary columns.

## 2. Schema

| column            | meaning                                                              |
| ----------------- | -------------------------------------------------------------------- |
| `article`         | full abstract text                                                   |
| `<top>/<child>/…` | one column per label: `1` if the article has that label, else `0`    |

Label columns are named by their path, with spaces replaced by `_`. Examples:

- `exposure_routes/oral_intake/food`
- `biomonitoring/exposure_biomarker/blood/cord_blood`
- `biomonitoring/exposure_biomarker/hair_nail`

Label columns are **ancestor-inclusive**: If an abstract is tagged `x/y/z`,
then `x`, `x/y`, and `x/y/z` are all set to `1`.

### Conversion from the source format

The source encodes a label as a `--`-separated path ending in a trailing `--`,
with co-occurring labels joined by ` AND `:

```
exposure routes--oral intake--food-- AND Biomonitoring--exposure biomarker--hair nail--
```

We convert it because nested `--` + `AND` delimiters are hard to read and
parse. Each `AND`-joined label becomes its own column, and:

- the trailing `--` (a root artifact) is dropped
- `--` → `/`
- spaces → `_`
- text is lowercased

## Extras

- `taxonomy.json`: the label forest, precomputed from the gold labels.
- `taxonomy_preprocess.py`: rebuilds `taxonomy.json` from `corpus/cei/class/*.txt`.
- `taxonomy_viewer.py`: interactive Streamlit browser (one tree per tab, zoomable).

Usage (preprocess → json → viewer):

```bash
python taxonomy_preprocess.py
streamlit run taxonomy_viewer.py
```

`taxonomy_preprocess.py` and `taxonomy_viewer.py` were generated by AI (Claude Code).
